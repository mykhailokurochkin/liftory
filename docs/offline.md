# Offline та синхронізація

## Що працює

Після першого відкриття онлайн та входу застосунок може працювати з локальними вправами й тренуваннями без API. IndexedDB зберігає дані та чергу змін між перезавантаженнями сторінки. UI підтверджує збереження лише після успішної транзакції; помилка сховища або quota показується користувачу.

PWA кешує загальнодоступну оболонку та assets. OAuth/API-відповіді не потрапляють у service-worker cache. Авторизований профіль та записи лежать у IndexedDB окремо для кожного server user ID.

На iPhone service worker потребує HTTPS: HTTP за LAN-IP недостатньо. `localhost` є винятком на самому Mac. Перший запуск і Google login потребують мережі. Очищення даних браузера може видалити ще не синхронізовані записи; local cache не є резервною копією.

## Протокол

1. Зміна запису збільшує local revision. Той самий IndexedDB transaction створює незмінний pending snapshot, якщо його ще немає.
2. Pending mutation має власний UUID, очікуваний owner ID, base server version та snapshot. Повторення використовує ідентичні ID і payload.
3. API бере власника із перевіреної сесії й звіряє його з expected owner. Власник із payload ніколи не надає доступу до чужих даних.
4. PostgreSQL transaction перевіряє receipt `(userId, mutationId)` та fingerprint, порівнює версію, записує нову версію і receipt атомарно.
5. ACK прибирає лише свою mutation. Якщо користувач устиг внести нові зміни, вони залишаються й утворюють наступний snapshot.
6. Pull застосовує серверні записи до чистих локальних записів; локальні незавершені зміни зберігаються.

Результати API: `401/403` потребує повторного входу відповідним користувачем; `409 version_conflict` зберігає локальний і серверний варіанти та потребує вибору; мережевий збій залишає outbox для повторення. Lost ACK не створює дубль на сервері.

## Коли повторюємо

При запуску, поверненні на сторінку, події `online`, foreground timer та явній команді синхронізації. Успішне підключення до Wi-Fi ще не доводить доступність API; запити мають таймаути й обмежені повторення. Інший Google account не отримує чергу попереднього профілю.

Надсилання після закриття PWA або блокування iPhone не гарантується. Service worker не примушує reload під час тренування; кеші та IndexedDB мають версії. Несумісний запис не можна мовчки видаляти задля оновлення.
